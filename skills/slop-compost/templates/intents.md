# Template - intents (`<LEDGER>/intents.md`)

Two sections. Intents are never deleted: an ended intent moves from "Active" to "Ended" with the date it ended. Ids `I<n>` are never reused. Keep the user's own words.

```markdown
# Intents

## Active
- I1 "B2B only" (since 2026-10-01, run 2026-10-01)
- I3 "under $70/month to run" (since 2026-10-15, run 2026-10-15)

## Ended
- I2 "keep the RSS parser part" (2026-10-01 -> ended 2026-10-15, run 2026-10-15)
```
